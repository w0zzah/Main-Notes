### Memory & Variable Declaration:
Computer memory is stored sequentially where each storage cell is a byte in size. The address of a storage cell is its number in the sequence. When declaring a variable, you need to store

- name (token)
- address
- value
- type
	- name
	- size
	- encoding


### Data Encoding

### Little Endian vs Big Endian
- The least significant byte is stored at the lower address


### Pointers
Pointer vs Value
\*ptr -> Looks at the value stored in the address
&ptr -> Memory Location of pointer
&value -> Memory Location of Value
value -> the value stored inside
ptr -> literal value
