Information text

A database contains information necessary for the day-to-day operation of a Sports Physio clinic. The clinic provides assessment, treatment and rehabilitation of all types of injuries for both athletes and non-athletes. The database stores information about patients, therapists, therapies and appointments.

Run the Oracle script physio-script.sql; which contains statements to create and populate three tables for this database:

  • The Patient relation stores information about patients, such as the unique patient number, first and last name, email address, birthdate, phone number, and the account balance.

    PATIENT (PNum, FName, LName, BDate, Email, Phone, Balance)

  • The Therapist relation tracks information about each therapist, including a unique id, name, and address.

    THERAPIST (UserID, FName, LName, Address)

  • The Therapy relation stores a unique number for each therapy, description, and the billable units of time (in minutes).

    THERAPY (Code, Description, Duration)

create table PATIENT
(
  PNum integer not null primary key,
  FName varchar(15) not null,
  LName varchar(15) not null,
  email varchar(20) not null,
  BDate date not null,
  Phone varchar(15) not null,
  Balance number not null
);

create table THERAPY
(
  Code integer not null primary key,
  Description varchar(90) not null,
  Duration integer
);

create table THERAPIST
(
  TNum char(5) not null primary key,
  FName varchar(15) not null,
  LName varchar(15) not null,
  Address varchar(30) not null
);

Question text

(10 marks) Show the code and description of the most frequently used therapy, excluding Assessment and Massage.

Feedback

Question author's solution

select code, description
from therapy join included on therapy = code
where Description not in ('Assessment', 'Massage')
group by code, description
having count(*) >=  ALL (
                        select count(code)
                        from therapy join included on code = therapy
                        where description not in ('Assessment', 'Massage')
                        group by code
                        );

Question d

Complete
Mark 2.50 out of 15.00
Flag question

Question text

(15 marks) Modify the database to enforce a condition that a patient can only have one appointment on a given day. Show that your modification works.

Feedback

Question author's solution

The requirements of this question could be satisfied by either: adding a new constraint to the APPOINTMENT table or; creating a trigger.

Add constraint

ALTER TABLE Appointment
add constraint one_PerDay unique(Patient,SDate);

Create trigger

create or replace trigger One_PerDay
BEFORE INSERT or UPDATE on Appointment
for each row
declare No_Sessions integer;
    begin
        select count(*) into No_Sessions
        from appointment
        where Patient = :new.Patient and SDate = :new.SDate;
    if (No_Sessions > 0) then
        raise_application_error (num => -20009,
        msg => 'There is already a session on that date!');
    end if;
    end;
    /

Demonstration

The following insert fails as the patient already has an appointment on that day.

insert into Appointment values(91,156465,'JR085','6/10/2026','14:00');

Question text

(12 marks) Create a view which will contain the following information about all appointments planned for today: the names of the patient and the therapist, start time, and the appointment length. Order the tuples by the start time. The query should be able to be executed on any day.

Feedback

Question author's solution

create or replace view DailySchedule (PatientFname, PatientLName, TherapistFname, TherapistLName, StartTime, Length) as
    select P.Fname, P.Lname, T.Fname, T.LName,STime, sum(Duration)
    from Patient P, Therapist T, Appointment A, Included, Therapy
    where Patient = PNum and
        Code = Therapy and
        Therapist = Tnum and
        A.SessionNo = Included.SessionNo and
        SDate = trunc(sysdate)
    group by P.Fname, P.LName, T.FName, T.LName, Sdate, Stime
    order by STime;

Question b

Not answered
Marked out of 14.00
Remove flag

Question text

(14 marks) Modify the database to enforce a condition that the total length of an appointment cannot be longer than 90 minutes. Provide an example to show that your modification works.

Feedback

Question author's solution

create or replace trigger Add_Therapy
BEFORE INSERT on INCLUDED
for each row
declare
    Existing_Length integer := 0;
    Therapy_Length integer :=0;
begin
    -- get the duration of the session before insert
    select sum(Duration) into Existing_Length
    from therapy join included on included.therapy = code
    where SessionNo = :new.SessionNo;
    -- get the duration of the new therapy
    select Duration into Therapy_Length
    from therapy
    where Code = :new.therapy;
    if ((Existing_Length + Therapy_Length) > 90) then
        raise_application_error (num => -20099,
        msg => 'Sessions cannot be longer than 90 minutes!');
    end if;
end;
/

Demonstration

Step 1: Find the longest session:

select sessionno, sum(duration) as duration
from included
join therapy on code = therapy
group by sessionno
order by duration desc;

We can see that session 67 is 65 minutes long.

Step 2: Find a suitably long therapy, such that including it will exceed the time limit:

select *
from therapy
order by duration desc;

Therapy 21 takes 30 minutes, so including it in session 67 would take the session to 95 minutes — violating the condition set out by the trigger. Therefore the following fails:

insert into included values (67, 21);

Question text

(4 marks) The clinic needs to be fumigated for black mold on October 14. Write a statement(s) to cancel all appointments on that date.

Feedback

Question author's solution

Step 1: Delete included therapies from impacted appointments:

delete from included
where sessionno in (
    select sessionno
    from appointment
    where sdate = '14/10/2026'
);

Step 2: Delete impacted appointments:

delete from appointment
where sdate = '14/10/2026';
