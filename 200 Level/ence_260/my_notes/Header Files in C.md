A header file in C is a .h file that contains declarations of functions, macros, constants, data types, and other reusable definitions. It is included in a program using the #include preprocessor directive to access standard library fundtion and user-defined declaration.
- Using Header files promotes code reusability by allowing common declarations to be shared across myltiple source files.
- Provides access to standard library functions and user defined components using the #include directive.


```c
// For header files in sys/default
#include <filename.h>

// For user defined in the same directiory
#include "filename.h"
```
