
#### Basic Variables
```c
int // Signed 32bit integer (-2,147,483,648 -> 2,147,483,647)
uint32_t // Unsigned 32bit integer (0 -> 4,294,967,295)
int32_t // Signed 8bit integer (-2,147,483,648 -> 2,147,483,647)
uint8_t // Unsigned (0 -> 255) or (0x00 -> 0xFF) or (2^8  -1)
```
