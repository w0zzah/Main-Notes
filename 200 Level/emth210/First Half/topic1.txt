EXACT AND INEXACT DIFFERENTIALS

A differential
P (x, y) dx + Q(x, y) dy
is called exact if and only if there is a function f (x, y) such that
df = fx dx + fy dy = P dx + Q dy

(6)

i.e. a differential is exact if and only if it is equal to the total differential of a function
(called f here). Otherwise P dx + Q dy is inexact. Combining (6) and equality of mixed
partial derivatives gives a quick test for exactness:

P dx + Q dy EXACT ⇐⇒ Py = Qx
Test your understanding of this derivation by showing that in 3D with P dx+Q dy +R dz,
exactness requires all of the following to hold: Py = Qx ; Pz = Rx ; and Qz = Ry .

LAGRANGE MULTIPLIERS (CONSTRAINED MAXIMA
AND MINIMA)

In 2D a point (x0 , y0 ) is called a stationary point of the function f (x, y) if and only if the
function is flat in every direction: ∇f |(x0 ,y0 ) = 0.

Why? First, if this is so then for any direction u, the directional derivative Du f = ∇f ·u =
0 at (x0 , y0 ): f is flat at (x0 , y0 ). Conversely, if ∇f ̸= 0 then taking u = ∇f /∥∇f ∥ gives
Du f > 0 and D−u f < 0 – there is a direction in which f is decreasing and another in
which it is increasing; f is not flat. Hence f is stationary (“flat”) at (x0 , y0 ) precisely
when (“if and only if”) the gradient of f at (x0 , y0 ) is zero.

Some stationary points are minimisers (also called minima or minimums, singular: minimum). For example, the point (x0 , y0 ) = (0, 0) is a minimiser of the function f = x2 + y 2 .
Stationary points also include maximisers and saddles. An example of a maximiser is
f = −(x2 + y 2 ) at the point (x0 , y0 ) = (0, 0). Similarly (x0 , y0 ) = (0, 0) is a saddle point
of f = x2 − y 2 .

WHEN A CONSTRAINT IS PRESENT

In practice we often have constraints limiting where (x, y) can be. For example, we may
want to
• maximise altitude while staying on a path,
• maximise strength for a fixed cost,
• minimise cost for a fixed strength,
• minimise surface area to contain a fixed volume,
• maximise efficiency for a fixed power output,
and so on.
We are looking for constrained maximums and constrained minimums. These are points
satisfying the constraint where the function is flat in a particular direction (along the
constraint curve), and we call them critical points 2 .
We will usually call the function we are maximising or minimising f (x, y), and the constraint curve c(x, y) = 0.
Mathematically, we define a critical point of f (x, y) satisfying the constraint c(x, y) = 0
as a point at which Du f = 0 for all directions u tangential to the constraint – the only
directions in which we can move if we are constrained to move along c(x, y) = 0.
Since Du f = ∇f · û and u ̸= 0, ∇f and u are orthogonal, so ∇f is orthogonal to the
constraint (or is zero). But assuming ∇c ̸= 0, ∇c is also orthogonal to the constraint,
since the gradient vector of a function is always orthogonal to its level curves. That means
∇f must be parallel to ∇c (or zero).
In notation: ∇f = λ∇c for some λ ∈ R. Here, λ is known as a Lagrange multiplier.
2

There are several other uses of “critical point”. E.g., a point at which the gradient of a function

functions have well-behaved gradients.
